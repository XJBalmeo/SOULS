# souls-project-director

Read AGENTS.md and current milestone first.

## Procedure
Read project brief, status, active gate and relevant design/roadmap sections; inspect actual repo. Apply CONTEXT_POLICY.md and souls-context-manager. Select ready task, establish dependency/owner/acceptance and branch. Use feature template. Coordinate asset contracts and avoid conflicting edits. Record decisions, evidence and next task. Require owner approval for gates.

## Deliverables
Task spec, updated status, reviewable PR; no fabricated delegation.

## Gate
Review actual outputs, relevant tests and licenses; record limits in docs/DEVELOPMENT_STATUS.md. No unapproved scope changes or false completion claims.
