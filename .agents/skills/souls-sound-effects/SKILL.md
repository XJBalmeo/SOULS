# souls-sound-effects

Read AGENTS.md and current milestone first.

## Procedure
Use event list from combat/animation specs. Generate jsfxr or licensed organic effects; review model/source rights. Trim, normalize and export with FFmpeg. Sync to animation events, vary repeats, test volume and simultaneous sounds.

## Deliverables
SFX manifest, audio files, event mapping and playback evidence.

## Gate
Review actual outputs, relevant tests and licenses; record limits in docs/DEVELOPMENT_STATUS.md. No unapproved scope changes or false completion claims.

## v1.1 — Parry Death
Parry Death: arrival, telegraph, strike, parry, revive and failure sounds; sync event and test pause/cleanup.
