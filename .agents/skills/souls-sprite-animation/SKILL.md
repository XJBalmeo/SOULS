# souls-sprite-animation

Read AGENTS.md and current milestone first.

## Procedure
Read ANIMATION_STANDARD; verify 100x100 baseline and custom boss dimensions. Use approved reference, PixelLab candidates and Aseprite/LibreSprite cleanup. Export explicit frame geometry, anchor, timing, loop, active frames and SFX events; preview and test Phaser.

## Deliverables
PNG sheets, metadata, preview, timing verification.

## Gate
Review actual outputs, relevant tests and licenses; record limits in docs/DEVELOPMENT_STATUS.md. No unapproved scope changes or false completion claims.
