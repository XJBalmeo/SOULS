# Enemy roster — proposed designs

Minimum five regular enemy types per chapter plus one distinct boss; six is target. Only rat is existing in inspected code. Names, art and attacks are proposals pending approval. Each enemy gets a design spec, assets, AI, sound, placement and QA. Reuse ground melee, ranged, flying, heavy and support behaviors.

## Famine

| Enemy | Role / behavior |
|---|---|
| Scavenger Rat | Existing patrol, pursuit, bite |
| The Starved | Slow approach, telegraphed lunge |
| Hollow Archer | Aim, shoot, reload |
| Carrion Crow | Hover, dive, recover |
| Rot Carrier | Poison cloud, area denial |
| Gut Crawler | Low-profile rush |

**Boss proposal:** Hollow King — giant crowned skeletal rat; bite and charge, optional faster phase.
